h3 Integers

java provides 4 types of Int
Datatype	Size	Range
- byte	1	-128 to 127
- short	2	-32768 to 32767
- int	4	-2147483648 to 2147483647
- long	8	-9223372036854775808 to +9223372036854775807


* Num. without decimal point is Integers and with decimal point is real number called float.

* If, we'll assign bigger value to the datatypes it will show error.
like byte max range is 127
if we do like, 
byte a = 300; //it will show error.

* In order to treat an Int as long int, we have to add suffix L or l at it's end.
long int a = 364l*1000;

* We can unse underscores between digits in a no., to improve the readability of code.
long creditcardno = 1234_6462_5116_6489;

h3 Char Data Type

✅ What is char in Java?
char is a primitive data type in Java.

It is used to store a single character like 'A', '5', or '$'.

But internally, it actually stores a number (code point) which represents a character.

🧬 What is Unicode?
Unicode is a global character encoding standard that:

✅ Assigns a unique number (called code point) to every character
✅ Supports all major languages — English, Hindi, Chinese, Arabic, Emoji, etc.
✅ Examples:

Character	Unicode	Java char
'A'	U+0041	char c = 'A';
'अ'	U+0905	char c = 'अ';
'你'	U+4F60	char c = '你';
'😊'	U+1F60A	stored as surrogate pair

📏 Difference from ASCII
Feature	ASCII	Unicode
Characters	Only 128 (basic English)	Over 1.4 million code points
Size	7-bit or 8-bit	16-bit (Java char) and beyond
Language Support	Only English letters	Almost all world languages
Java Support	❌ Limited	✅ Fully supported in Java

    }
}
